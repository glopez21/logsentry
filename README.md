# logsentry

Security log parsing toolkit — multi-format ingestion with MITRE ATT&CK heuristic detection.

**Intent**

LogSentry is a security log parsing and enrichment toolkit designed for SOC analysts who need to work across multiple log formats without a full SIEM deployment.

**Tech stack**

- Python
- MITRE ATT&CK
- CLI
- YARA
- MISP
